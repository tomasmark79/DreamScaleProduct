A FEW GOOD QUESTIONS

Before the
first note.

Will it work with my keyboard?+

The current project includes mappings for Arturia KeyLab 49 MKII and a 61-key variant. Physical LED alignment and MIDI setup matter, so a confirmed compatibility list will accompany the first kits. We are not promising universal keyboard support.

Does the light cover black keys too?+

Yes. The 1-metre strip packs 144 LEDs per metre, giving the mapping enough resolution to reliably cover both white and black keys on supported keyboard layouts. The dense spacing lets us assign LEDs to individual keys instead of relying on a widely spaced strip. Full-width coverage depends on your keyboard's dimensions and the selected mapping.

Do I need Bitwig Studio?+

No. DreamScaler includes a standalone piano tool for exploring scales and light effects. Bitwig integration adds session-connected scale changes and project-specific settings.

Is this a keyboard or a light system?+

DreamScaler is an LED light system and companion software for a keyboard you already own. A keyboard and computer are not included.

Is the interactive preview the actual software?+

The preview is a browser illustration of scale coloring. It does not connect to MIDI or hardware. Watch the demonstration video to see the existing DreamScaler hardware and software in use.

When can I get one?+

The first DreamScaler set is being prepared. Pricing, availability, supported systems and final setup instructions will be announced here before orders open.
